# Portfolio Luiz Otavio

Portfolio pessoal desenvolvido com React, Vite, TypeScript e Tailwind CSS.

## Rodando localmente

```sh
npm install
npm run dev
```

## Scripts

```sh
npm run build
npm run lint
npm test
```

## Conteudo

Os projetos publicos ficam em `public/projects.json`, com fallback em `src/data/projects.ts`.
A rota escondida `/admin` permite publicar novos projetos quando as variaveis de ambiente do GitHub estiverem configuradas.

## Variaveis de ambiente

```txt
RESEND_API_KEY=
CONTACT_TO_EMAIL=bgoficial2026@outlook.com
CONTACT_FROM_EMAIL=Portfolio <onboarding@resend.dev>
ADMIN_PASSWORD=
GITHUB_TOKEN=
GITHUB_OWNER=Luiz-otavio-bg
GITHUB_REPO=port
GITHUB_BRANCH=main
```
